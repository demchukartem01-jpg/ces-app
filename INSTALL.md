# Установка новостного конвейера в ces-app

Версия под CommonJS (`require`), как в твоём проекте.
Работает через твой существующий экземпляр бота — второй не создаётся,
поэтому 409 Conflict не повторится.

## 1. Зависимости

В `package.json` в блок `dependencies` добавь две строки:

```json
"dependencies": {
  "node-telegram-bot-api": "^0.66.0",
  "express": "^4.18.2",
  "mongodb": "^6.3.0",
  "rss-parser": "^3.13.0",
  "node-cron": "^3.0.3"
}
```

Render выполнит `npm install` сам при деплое — терминал не нужен.

## 2. Папка

Положи папку `news/` в корень репозитория, рядом с `server.js` и `bot.js`.

## 3. Переменные окружения на Render

Добавить три (BOT_TOKEN и MONGODB_URI уже есть):

```
CHANNEL_ID=-100...        # ID канала
ADMIN_CHAT_ID=...         # твой личный ID, без минуса
ANTHROPIC_API_KEY=...     # новый ключ
```

## 4. Две вставки в код

### Вставка А — запуск конвейера

После того места, где создаётся бот:

```js
const { startNewsPipeline } = require('./news');

startNewsPipeline(bot).catch(e => console.error('[news] старт:', e.message));
```

Если у тебя уже есть подключённый `db` — передай вторым аргументом:
`startNewsPipeline(bot, db)`. Это сэкономит соединение к Atlas.

### Вставка Б — обработка кнопок

В САМОЕ НАЧАЛО существующего обработчика `callback_query`:

```js
const { handleNewsCallback } = require('./news/publish');

bot.on('callback_query', async (cb) => {
  if (await handleNewsCallback(bot, cb)) return;   // <-- эта строка первой

  // ... дальше твоя существующая логика CES без изменений
});
```

Функция вернёт `true` только для кнопок с префиксом `news:`.
На кнопках тестов вернёт `false`, и твой код отработает как раньше.

## 5. Проверка без ожидания cron

Чтобы не ждать начала часа, временно добавь:

```js
const { collect } = require('./news');
setTimeout(() => collect(bot), 10000);   // через 10 сек после старта
```

После проверки — удали.

## 6. Порядок

1. Сделай ветку в git перед вливанием.
2. Задеплой, найди в логах Render строку `[news] конвейер запущен`.
3. Дождись первых черновиков в личке.
4. 2-3 недели жми кнопки, правь `AUDIENCE_BRIEF` в `config.js`.
5. Когда 9 из 10 уходят без правок — ставь `MODERATION: false`.

## Про Render

Бесплатный тариф усыпляет сервис, `node-cron` засыпает вместе с ним.
UptimeRobot (он у тебя уже был в планах) или платный инстанс — иначе
конвейер работает через раз.
